# The Legend of Dengdeng · 登登的奇幻山谷冒险

献给 **登登** 的独一无二 3D 开放世界童话冒险游戏 —— 融合《塞尔达传说：旷野之息 / 王国之泪》与吉卜力水彩美学，基于 **Three.js** 与 **@pixiv/three-vrm** 精心构筑。

在线游玩：**https://realjun.github.io/legend-of-dengdeng/**

---

## ✨ 世界与玩法亮点

### 1. 🏡 星光樱花木屋与一家四口 (`src/entities/FamilySystem.js`)
- **星光樱花木屋**：坐落于东南暖阳高台 `(34, 26)`，门前樱花树下燃着咕嘟冒热气的**爱心料理锅**，烟囱袅袅升起炊烟。
- **老公（专属爱心主厨）**：按真实照片定制黑色圆领乐高印花卫衣与清爽黑色短发造型；靠近会热情挥手并冒出小爱心，按 `F` 互动可听暖心日常对话，还能品尝热汤获得 **90 秒粉金爱心剑气加成**。
- **蓝猫妹妹 · Broccoli（母）**：深蓝灰丝绒毛色、温柔浅橄榄绿眼眸与胸前标志性的一小撮白毛；会灵巧引路靠近未解开的秘密宝箱，按 `F` 可温柔撸猫与投喂小鱼干。
- **火焰重点色暹罗弟弟 · Jelly（公）**：与 Broccoli 体型相仿的修长奶油白身躯、烤杏橘色鼻梁面具与虎斑额纹、橘色耳尖长尾及澄澈蓝眼睛；战斗时会勇敢扑击助阵眩晕小怪，按 `F` 撸猫会翻开雪白肚皮撒娇！

### 2. ⚔️ 大师之剑 · 海利亚盾 · 星羽滑翔翼 (`src/player/VrmDengdeng.js`, `src/effects/CombatEffects.js`)
- **大师之剑三连斩 / 空中跳劈**：按 `J` 或单击左键挥出三段武术连击；空中挥剑触发头顶劈砍震地波。
- **蓄力 360° 回旋斩**：长按 `J` 纳刀聚气，松开释放黄金旋风斩与大范围割草气浪。
- **海利亚盾防御与完美盾反**：按住 `K` 或右键举盾锁定戒备移动；按 `E` 或 `L` 挥盾完美弹反，可将星炮偶发射的能量球**原路加速弹回秒破强敌**！
- **专属双喵星纹滑翔翼 (`星羽滑翔翼`)**：空中再按 `Space`（或在**黄金上升气流**中按 `Space`）双手高举展开绘有八芒星与双猫爪徽章的滑翔翼，乘风飞上云海。
- **海利亚盾牌滑草冲浪 (`踩盾滑草`)**：按 `C` 键一跃踏上海利亚盾顺坡冲浪（滑行中按 `Space` 可施展 360° 旋盾特技跳），还能参加山坡上的**五道星环滑草小挑战**赢取小鱼干！

### 3. 🌍 奇幻新地图与五大心愿星徽解谜 (`src/world/ExpandedBiomes.js`, `src/world/PuzzleSystem.js`, `src/world/SkyIslandSystem.js`, `src/world/PlayfulActivities.js`)
1. **🎵 时光遗迹 · 四季音律台 `(-26.5, 19.5)`**：聆听石碑旋律，用剑按「天青蓝 → 暖阳金 → 樱花粉 → 翡翠绿」顺序敲响水晶柱，解封 **心愿星徽 ①**。
2. **🍂 黄金银杏双喵圣坛 `(24, -34)`**：带着 Broccoli 与 Jelly 踏上猫爪符文台释放回旋斩或盾反共鸣，解封 **心愿星徽 ②**。
3. **🌿 星语树篱迷宫 `(-40, -34)`**：探索 9×9 花卉树篱迷宫，寻找角落秘藏小鱼干礼盒与中央高台 **心愿星徽 ③**。
4. **🍄 奇幻荧光蘑菇秘境 `(54, -18)`**：穿梭于发光巨型蘑菇与漂浮荧光孢子之间，击败调皮小怪兽解封 **心愿星徽 ④**。
5. **☁️ 云端樱花誓言浮岛 `(0, 32, -16)`**：乘黄金上升气流飞抵双子山前的天空浮岛，敲响**云端同心钟**解封 **心愿星徽 ⑤**。
6. **🪷 镜湖巨型发光睡莲与同心许愿泉 `(-18.2, -4.6)`**：踩着湖面盛开的巨型睡莲跳台登临白玉小岛，投下星瓣许下给登登的专属心愿。

### 4. 🏮 登登冒险手账、拍立得纪念相机与漫天孔明灯烟花盛典 (`src/ui/AdventureJournal.js`, `src/ui/PolaroidCamera.js`, `src/effects/CelebrationSystem.js`)
- 按 `M`（或点击左上角 **📖 手账**）随时查看五枚星徽收集进度，或点击 **8 张风景明信片一键传送**至任意景点。
- **右下角实时地形雷达小地图 (`src/ui/Minimap.js`)**：预烘焙等高线草海、镜湖木桥、睡莲小岛、樱花木屋与 9×9 迷宫墙体，实时显示登登朝向、老公位置、Broccoli 与 Jelly 猫耳图标及五枚星徽方向（点击小地图切换近景/全景缩放，按 `N` 切换随视角/正北锁定）。
- 按 `P`（或点击右上角 **📷 拍立得**）随时将眼前的 3D 画面定格成印有**双猫爪印章与浪漫题词的复古拍立得纪念卡**，支持一键下载保存 PNG。
- 集齐五枚心愿星徽（或随时在手账中点击 **「✨ 放飞漫天心愿孔明灯」**），天空将化作璀璨星夜，64 盏金色孔明灯自镜湖冉冉升空，伴随八音盒专属小夜曲、漫天烟花与致登登的浪漫寄语。

## 🎮 操作一览

| 按键 / 鼠标 | 动作 |
| --- | --- |
| `W A S D` / `Shift` | 漫步 / 疾跑 |
| `Space` | 跳跃（空中再按展开/收起 **星羽滑翔翼**；滑草时触发 **360° 旋盾特技跳**） |
| `C` | 跃上/收起 **海利亚盾牌滑草冲浪** |
| `J` / 鼠标左键单击 | 拔剑三连斩（空中触发 **跳劈下砸**） |
| 长按 `J` 松开 | 蓄力释放 **360° 黄金回旋斩** |
| 按住 `K` / 鼠标右键 | 举起 **海利亚盾** 防御与锁定戒备步 |
| `E` 或 `L` | **完美盾反**（可反弹星炮偶能量球、震晕盾牌小树精） |
| `R` | 手动收剑归鞘 / 拔出剑盾 |
| `F` 或点击互动提示 | 撸猫投喂小鱼干 / 与老公对话喝汤 / 许愿敲钟开宝箱 |
| `M` | 打开 / 关闭 **登登的冒险手账与快速旅行明信片** |
| `N` / 点击右下角小地图 | 切换小地图 **随视角 / 正北锁定**，点击圆盘切换 **近景 / 全域视野** |
| `P` | 拍下 **登登专属拍立得纪念照片**（支持一键下载保存） |
| 鼠标左键拖拽 / 滚轮 | 360° 自由环视相机 / 近景写真与远景缩放 |
